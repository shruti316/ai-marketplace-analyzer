## 1. Executive Summary

This investigation provides the definitive provenance and leakage analysis of the supervision target used in the Multimodal Gated Fusion models (both ML V1.0 baseline and Multimodal Vision V1.1 candidate).

### Core Finding
The supervision target $y \in \{0, 1\}$ (where $y = 1$ indicates `ELEVATED_MULTIMODAL_ANOMALY`, $N_{\text{pos}} = 154$, $N_{\text{neg}} = 3,489$) is **not** an independently verified ground-truth fraud label. It is a **purely deterministic, rule-based proxy** generated by `MultimodalFusionEngine.fuse_assessments` in `src/trust_engine/multimodal_fusion.py`.

Furthermore, a significant structural leakage exists:
- Of the 154 positive cases in the dataset, **137 ($88.96\%$)** are triggered by a single physical event: **cross-product hero image reuse**.
- In the pipeline, this single event was counted **twice**:
  1. Once in the visual modality as `image_cv_has_anomaly = True` (type `CROSS_PRODUCT_IMAGE_REUSE`).
  2. Once in the graph topology modality as `graph_topology_has_anomaly = True` (type `CROSS_PRODUCT_GRAPH_LINK_ANOMALY` via `GRAPH_SHARED_IMAGE_EDGE`).
- Because the threshold for `ELEVATED_MULTIMODAL_ANOMALY` is $\ge 2$ active anomaly modalities, this single visual reuse link automatically elevated all 137 items into the positive target class.
- When the ML feature matrix $X$ was enriched in V1.1 with `cv_is_cross_product_reuse` and `graph_degree_centrality`, the ensemble classifier was supplied with the exact boolean predicates that constructed the target.

### Empirical Proof of Rule Reconstruction
A simple 2-clause boolean rule with zero machine learning:
$$\hat{y} = (\texttt{cv\_is\_cross\_product\_reuse} > 0.5) \lor [(\texttt{review\_has\_duplicate} > 0.5) \land (\texttt{pricing\_robust\_z} > 0.4)]$$
reproduces the target $y$ with:
- **Accuracy:** $99.70\%$ ($3,632 / 3,643$)
- **Precision:** $96.13\%$ ($149 / 155$)
- **Recall:** $96.75\%$ ($149 / 154$)
- **False Positives:** Only 6 items
- **False Negatives:** Only 5 items

Therefore, the high metrics reported for V1.1 (ROC-AUC $0.9988$, PR-AUC $0.9845$) represent **Target Rule Reconstruction Fidelity**, not independent statistical discovery of hidden e-commerce fraud.

```
        │

  ├── Modality 1: Review NLP    ──> has_anomaly = True IF has_dup OR has_disc

  ├── Modality 3: Pricing       ──> has_anomaly = True IF is_price_outlier OR mrp_breach

  └── Modality 5: Graph Topo    ──> has_anomaly = True IF shared_image_edge > 0
        │
        ▼

  active_anomaly_modality_count = sum([mod.has_anomaly for mod in available_modalities])
        │
        ▼
[Overall Risk Tier Decision]
  ├── IF available_core_modalities < 2:  UNASSESSED_SPARSE_DATA (1,088 items)

  ├── ELIF active_anomaly_modality_count == 1: MODERATE_SINGLE_MODALITY_ANOMALY (413 items) -> y = 0
  └── ELSE:                                    LOW_OBSERVED_ANOMALY (1,988 items) ---------> y = 0
```

## 5. Why CLIP Performance Differed Between Benchmark and Fusion

This investigation conclusively answers why CLIP exhibited high benchmark scores but low catalog fusion contribution:
1. **The Controlled Benchmark (ROC $0.9962$, PR $0.9965$):**
   Evaluated cross-modal alignment on synthetic and hard-negative mismatched pairs (e.g., cosmetics image paired with consumer electronics title). In this task, semantic mismatch is the direct prediction target.
2. **The Catalog Fusion Task (PR $0.1273$):**
   The prediction target is `active_anomalies >= 2` (dominated by image reuse and price/review manipulation).
   - Sellers who engage in cross-product image reuse (Cluster A) typically reuse authentic product photos from competitor listings of the same product. Their photos match their titles!
   - Sellers who manipulate reviews or discount pricing (Cluster B) still display genuine photos matching their titles.
   - Consequently, the distribution of CLIP similarity between $y = 0$ ($0.318$) and $y = 1$ ($0.304$) is nearly indistinguishable.
   - A pure vision-language model cannot and should not be expected to predict pricing corridor breaches or review ring spam from image-title alignment alone.

## 6. Corrective Actions for Release Governance

1. **Registry Decoupling:**
   In `src/data/target_registry.py`, this target was already formally cataloged as:
   `TARGET_DEPRECATED_ELEVATED_RISK_SURROGATE` (`DEPRECATED_CIRCULAR_PROXY`).
   The documentation must explicitly declare that the ML fusion model is an **automated proxy ranker / surrogate approximation engine**, not an independent legal fraud detector.
2. **Feature Stratification & Documentation:**
   When reporting model metrics, documentation must present:
   - **Full Proxy Reconstruction Benchmark:** (Includes all signals; ROC $0.9988$, PR $0.9845$).
   - **Independent Generalization Benchmark:** (Ablating direct duplicate predicates to evaluate non-circular signals like CLIP and pricing distributions).
3. **Phase 3 Backend Contract:**
   The backend must clearly expose `active_anomalies` as **observable evidence items**, and explain that the machine learning risk probability represents the likelihood that an investigator reviewing the listing will find multi-modal policy non-compliance.
